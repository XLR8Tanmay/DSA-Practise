* Patterns in Recursion - Subsequence Problems
1. Print All Values
 - Pick / Not Pick Approach
2. Print Single Value
 - In base case, use true or false as return statement (Function return type boolean)
 - If any recursion call, gives a true, break out of the recursion loop.
3. Print Count
 - In base case, use 0 or 1 as return statement (Function return type int)
 - Two different variable stores indicating left and right recursion call
 - At the end return l + r
4. Print Arrays with sum = K 
 - Use a sum parameter in the recursive function call
 - In base case, if sum == k, print the array.

* Merge Sort:
 - Optimized sorting algorithm which uses the "Divide and Merge" strategy
 - Use two pointers, if left array val < right array val, add left array val to the result and vice versa.
 - While merging, only use the low and high pointers to decide which index is to be updated in array. 

* Combination Sum:
 - Uses pick/non-pick approach with repetition on indexes.
 - If index reaches end of the array, check if target is 0, if yes, print the data structure, else return.
 - In pick case, if target can still accomodate the value at current index, subtract the value from target and do the recursion call on the same index with minimized target.
 - In non-pick case, just move to the next index.
